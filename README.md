# Simple ATM System 🏧

A simple ATM simulation system built using **Java**. The project demonstrates fundamental Java programming concepts through a basic banking interface.

## 📌 About the Project

The Simple ATM System simulates common ATM operations, allowing users to interact with an account and perform basic transactions.

This project was created to practice Java programming fundamentals and object-oriented programming concepts.

## ✨ Features

* 🔐 PIN authentication
* 💰 Check account balance
* 💵 Deposit money
* 💸 Withdraw money
* 🚪 Exit the ATM system
* ⚠️ Basic input validation

## 🛠️ Technologies Used

* **Java**
* **Java Scanner** for user input
* **Object-Oriented Programming (OOP)** concepts

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/simple-atm-system.git
```

### 2. Navigate to the project folder

```bash
cd simple-atm-system
```

### 3. Compile the Java program

```bash
javac Main.java
```

### 4. Run the program

```bash
java Main
```

If your main Java file has a different name, replace `Main.java` with the correct filename.
